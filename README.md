# ควิซรถเมล์ปลอดภัย (Live quiz แบบ Kahoot)

ผู้เล่นเปิดลิงก์เดียวกัน ใส่ชื่อ แล้วเล่นได้เลย ไม่ต้องล็อกอิน
4 ข้อ ข้อละ 20 วินาที มีกราฟแท่ง เฉลยพร้อมคำอธิบาย ตารางอันดับ และโพเดียมตอนจบ

## ลองรันในเครื่อง
ต้องมี Node.js 18 ขึ้นไป

    npm install
    npm start

- หน้าผู้จัด (เปิดขึ้นจอโปรเจกเตอร์): http://localhost:3000/host
- หน้าผู้เล่น: http://localhost:3000/

ถ้าให้คนในวง Wi-Fi เดียวกันเล่น ให้ใช้ IP ของเครื่อง เช่น http://192.168.1.20:3000/

## เอาขึ้นเว็บให้ทุกคนเล่นผ่านเน็ตได้ (ฟรี) ด้วย Render
1. อัปโหลดโฟลเดอร์นี้ขึ้น GitHub
2. ที่ render.com กด New > Web Service แล้วเลือก repo นี้
3. Build command: `npm install`  Start command: `npm start`
4. ที่ Environment ตั้ง `HOST_KEY` เป็นรหัสลับ เช่น `bus2026`
5. หน้าผู้จัดคือ `https://ชื่อแอป.onrender.com/host?key=bus2026`
   หน้าผู้เล่นคือ `https://ชื่อแอป.onrender.com/` (มี QR code ให้สแกนที่หน้าผู้จัด)

แพ็กเกจฟรีของ Render จะหลับเมื่อไม่มีคนใช้ ให้เปิดหน้าผู้จัดทิ้งไว้ก่อนเริ่มสัก 1-2 นาที
และอย่ารีสตาร์ตเซิร์ฟเวอร์ระหว่างเล่น เพราะคะแนนเก็บไว้ในหน่วยความจำ

## วิธีเล่น
1. ผู้จัดเปิดหน้า /host ผู้เล่นสแกน QR ใส่ชื่อ
2. กด "เริ่มเกม" แต่ละข้อจับเวลา 20 วินาที ถ้าทุกคนตอบครบจะเฉลยทันที (หรือกด "ปิดรับคำตอบเลย")
3. เฉลย > ดูอันดับ > ข้อต่อไป จนจบ 4 ข้อ แล้วโชว์โพเดียม

## การคิดคะแนน
- ตัวเลือกที่ถูกได้ตัวละ 1 คะแนน ตัวเลือกที่ผิดได้ 0 (ไม่หักคะแนน)
- ข้อ 1-2 ทุกตัวเลือกถูก เลือกได้ 1 ข้อ
- ข้อ 3 เฉลย 2 และ 3, ข้อ 4 เฉลย 1 และ 3 (เลือกได้หลายข้อ)
- โบนัส +2 ให้คนที่ตอบถูกไวที่สุดในแต่ละข้อ (จับเวลาที่เซิร์ฟเวอร์)
  ข้อ 3-4 ต้องเลือกถูกอย่างน้อย 1 ข้อ และไม่เลือกข้อผิดเลย จึงมีสิทธิ์ได้โบนัส

## แก้คำถาม
แก้ในไฟล์ `questions.js` ได้เลย
เปลี่ยนเวลาต่อข้อได้ที่ `QUESTION_SECONDS` ใน `server.js`
